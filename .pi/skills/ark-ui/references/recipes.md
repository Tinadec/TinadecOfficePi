# Product-family recipes

Read only the family selected for the task.

## Ark: industrial information system

Use for tactical dashboards, operations consoles, media/news portals, game menus, and Rhodes-Island-adjacent requests.

- Palette: near-black, white, cyan `#18d1ff`; optional acid green for download/success only.
- Type: condensed/extended uppercase Latin + Source Han Sans-style CJK.
- Shell: black top bar, edge utilities, large art stage, lower metadata baseline.
- Geometry: 1px white rules, cyan active underline, squared controls, diagonal slash.
- Content pattern: `INDEX / INFORMATION / OPERATOR / WORLD / MEDIA`, paired with CJK labels and section indices.
- Art direction: blueprint scribbles, technical diagrams, desaturated environments, one high-detail character or artifact.
- Motion: masked lateral reveal, active cyan pulse, slow art parallax.
- Content ownership: let the stage own the current operation, the edge rail own navigation, and a single dossier own selected-unit detail. News lists use category + date + headline rather than dashboard cards.
- Depth adaptation: `minimal` keeps typography and a cyan state rule; `moderate` adds the black edge shell and one blueprint layer; `complex` adds a full dossier, indexed stage, and coordinated masks; `maximal` may recompose operation, archive, and media modes independently.
- Avoid: generic green terminal UI, all-cyan text, excessive card grids.

## Endfield: field engineering system

Use for construction, logistics, data tools, operational landing pages, industrial product sites, and high-contrast technical UI.

- Palette: `#191919`, off-white, signal yellow `#fffa00`; green only for verified/online state.
- Type: wide condensed display + Space Grotesk/technical sans.
- Shell: pale vertical rail, icon stack, large segmented image field, black utility docks.
- Geometry: rectangular tiles, long guide lines, clipped wedges, very large section numerals.
- Content pattern: action-first control strips, field codes, timeline/calibration labels, title blocks that overlap media.
- Motion: yellow wipe on load, directional clipped reveals, restrained breathing activity block.
- Avoid: hazard stripes everywhere, construction-yellow backgrounds behind long text, faux military warnings.

## Ex Astris: cosmic archive

Use for narrative archives, cultural/editorial sites, astronomy tools, character dossiers, and atmospheric premium-product pages.

- Palette: midnight blue/black, white, aqua `#46f6e6`; violet as rare secondary energy.
- Type: Source Han Serif-style CJK for narrative/display, technical sans for controls, fictional glyphs only as decoration.
- Shell: immersive full-bleed image, slim left navigation, orbital/ring controls, outlined pill actions.
- Geometry: circular instruments, fine lines, triangles, star-chart points, mask-faded tickers.
- Content pattern: archival notes, character name + title + voice metadata, sparse navigation.
- Motion: slow orbital rotation, stepped sprite/ticker animation, subtle point glints.
- Content ownership: let one named journey, record, or subject dominate the stage. Keep route notes, voice/author metadata, and selected chronology in separate archival bands.
- Depth adaptation: `minimal` uses serif contrast and one aqua point; `moderate` adds a slim archive rail and one ring; `complex` adds a multi-ring instrument, narrative dossier, and masked ticker; `maximal` may give journey, character, and notice modes separate constellations and transitions.
- Avoid: illegible invented alphabet for real content, fantasy filigree, saturated purple gradients over every surface.

## POPUCOM: playful platform system

Use for cooperative tools, playful onboarding, family-friendly games, campaign microsites, and colorful purchase/launcher flows.

- Palette: blue `#3994ff`, yellow `#ffcc1a`, orange `#ffa800`, off-white; add green/blue variants by function.
- Type: heavy friendly CJK sans + compact display face.
- Shell: dark dotted top bar above a bright illustrated field; pill actions grouped vertically.
- Geometry: rounded capsules, thick outlines, arrow nubs, offset shadows, halftone texture.
- Content pattern: one clear primary purchase/start action, platform badges, friendly character grouping.
- Motion: 2s floating layers, small arrow swing, button background roll, bouncy but short feedback.
- Content ownership: keep party readiness, selected challenge, and the next shared action visible. Use color as a gameplay or teammate category, not as decoration on every peer item.
- Depth adaptation: `minimal` uses friendly type and one rounded primary action; `moderate` adds the dotted shell and one offset-shadow layer; `complex` adds party state, challenge preview, floating geometry, and coordinated feedback; `maximal` may give lobby, challenge, and reward modes their own playful compositions.
- Avoid: using the industrial Ark shell with bright colors; over-inflated every element; motion that competes with the main action.

## Corporate: restrained studio identity

Use for portfolio, recruiting, studio/about, and black-box media showcase pages.

- Palette: black/charcoal, white, acid lime `#f3ff00`.
- Type: Source Han Sans-style UI with one geometric display face.
- Shell: translucent dark top bar, black panels over monochrome hero art, project carousel.
- Geometry: clean rectangles, light shadow, minimal lime rule/active state.
- Motion: quiet carousel and opacity/slide transition.
- Content ownership: let project imagery or a single statement dominate. Keep studio facts, roles, and contact actions in quiet editorial bands instead of operational telemetry.
- Depth adaptation: `minimal` uses monochrome type and a lime active rule; `moderate` adds a translucent header and image-led split; `complex` adds project sequencing, editorial metadata, and responsive media choreography; `maximal` means bespoke project narratives, not tactical decoration.
- Avoid: turning the corporate branch into a tactical HUD; the evidence is simpler and more restrained.

## Hybrid selection

Combine at most two families when product semantics require it. Keep the first family's shell and the second family's accent or illustration behavior. Example: an astronomy operations dashboard may use Endfield's shell with Ex Astris's circular instruments, while retaining one signal color.
